# 3D Process Page

차량 2D 이미지 또는 영상 파일을 3D 파일로 자동 변환하는 페이지입니다.

## 주요 기능

### 1. 테마 지원
- **Dark/Light 모드**: 우측 상단의 테마 토글 버튼으로 다크/라이트 모드 전환 가능
- 시스템 테마 자동 감지 지원

### 2. 파일 업로드
- **Drag & Drop**: 파일을 드래그하여 업로드 영역에 드롭
- **파일 선택**: 클릭하여 파일 선택 대화상자 열기
- **데이터 타입 선택**: 라디오 버튼으로 영상/이미지 선택
  - 영상: 비디오 파일 (video/*)
  - 이미지: 이미지 파일 (image/*)

### 3. 처리 단계 시각화

#### 영상 처리 단계 (6단계)
1. **프레임 추출**: 영상에서 프레임 추출
2. **이미지 전처리**: 추출된 프레임 전처리
3. **특징점 추출**: 이미지에서 특징점 추출
4. **3D 재구성**: 특징점을 기반으로 3D 모델 재구성
5. **메쉬 최적화**: 3D 메쉬 최적화
6. **3D 파일 생성**: 최종 3D 파일 생성

#### 이미지 처리 단계 (5단계)
1. **이미지 검증**: 이미지 유효성 검증
2. **특징점 추출**: 이미지에서 특징점 추출
3. **3D 재구성**: 특징점을 기반으로 3D 모델 재구성
4. **메쉬 최적화**: 3D 메쉬 최적화
5. **3D 파일 생성**: 최종 3D 파일 생성

### 4. 단계별 상태 표시

각 처리 단계는 다음 정보를 표시합니다:

- **상태 인디케이터**:
  - 🟢 초록색 점 (깜빡임): 현재 진행 중
  - ✅ 체크 아이콘: 완료
  - ❌ X 아이콘: 오류
  - ⚪ 회색 점: 대기 중

- **진행률**: 
  - 처리 중/완료 단계에 프로그레스 바 표시
  - 백분율(%) 표시

- **로그 뷰어**:
  - 드롭다운 형태로 로그 토글 가능
  - 타임스탬프와 함께 실시간 로그 표시
  - 스크롤 가능한 로그 영역

## UI 컴포넌트

### 사용된 Radix UI 컴포넌트
- `@radix-ui/react-progress`: 진행률 바
- `@radix-ui/react-radio-group`: 데이터 타입 선택
- `@radix-ui/react-label`: 폼 레이블

### 커스텀 컴포넌트
- `ThemeToggle`: 테마 전환 버튼
- `ProcessStep`: 단계별 처리 상태 컴포넌트

## 스타일링

- **Tailwind CSS**: 유틸리티 기반 스타일링
- **CSS Variables**: 테마별 색상 변수 사용
- **반응형 디자인**: 다양한 화면 크기 지원
