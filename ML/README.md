## 프로젝트 개요

### 이 시스템은 무엇인가요?

이 시스템은 **중고차의 예상 판매가격을 예측**하는 머신러닝 기반 웹 애플리케이션입니다. 

사용자가 차량 정보(제조사, 모델, 등급, 주행거리, 연식 등)를 입력하면, 학습된 인공지능 모델이 해당 차량의 예상 판매가격을 계산하여 보여줍니다.

### 왜 유용한가요?

- **중고차 판매자**: 적정 판매가격을 설정하는 데 도움
- **중고차 구매자**: 합리적인 구매가격을 판단하는 데 참고
- **중고차 딜러**: 빠르고 정확한 가격 평가 가능

### 핵심 원리 (간단 설명)

1. **과거 데이터 학습**: 수만 건의 실제 중고차 판매 데이터를 분석하여 패턴을 학습
2. **차량 그룹화**: 비슷한 특성을 가진 차량들을 클러스터(그룹)로 분류
3. **가격 예측**: 입력된 차량 정보를 바탕으로 가장 적합한 클러스터의 모델로 예측
4. **감가율 계산**: 신차가격 대비 얼마나 가치가 하락했는지(감가율)를 예측하고, 이를 바탕으로 판매가격 계산

```
예측 판매가 = 신차가격 × (1 - 감가율)
```

```
  - 구간 변환 (배기량, 가격 등)
  - 시간 피처 계산

[클러스터 결정]
  - 등급코드 + 배기량구간 + 가격구간으로 클러스터 찾기
    ↓
[모델 선택]
  - 해당 클러스터의 LGBM 모델 로드
    ↓
[예측 수행]
  - 감가율 예측
  - 판매가격 계산
    ↓
[결과 표시]
  - 예측 판매가
  - 감가율
  - 상세 정보
```

## 주요 기능 설명

### 1. 계층화된 차량 선택

사용자는 다음 순서로 차량을 선택합니다:

1. **국산/외제차** 선택
   - 국산차 또는 외제차 중 선택

2. **제조사** 선택
   - 선택한 국산/외제차에 따라 사용 가능한 제조사 목록이 자동으로 필터링됨
   - 예: 국산차 선택 시 → 현대, 기아, 쌍용 등

3. **대표차종명** 선택
   - 선택한 제조사에 따라 사용 가능한 차종 목록이 자동으로 필터링됨
   - 예: 현대 선택 시 → 쏘나타, 아반떼, 그랜저 등

4. **모델** 선택
   - 선택한 대표차종명에 따라 사용 가능한 모델 목록이 자동으로 필터링됨
   - 예: 쏘나타 선택 시 → 쏘나타 DN8, 쏘나타 뉴 라이즈 등

5. **등급** 선택
   - 선택한 모델에 따라 사용 가능한 등급 목록이 자동으로 필터링됨
   - 예: 쏘나타 DN8 선택 시 → 2.0 가솔린, 1.6 터보 등

6. **세부등급** 선택 (선택사항)
   - 일부 차량은 세부등급이 있을 수 있음
   - 없으면 "세부등급 없음" 선택

**왜 이렇게 복잡한가요?**
- 데이터의 정확성을 높이기 위해
- 존재하지 않는 차량 조합을 입력하는 것을 방지하기 위해
- 사용자가 쉽게 선택할 수 있도록 단계별로 필터링

### 2. 차량 상세 정보 입력

#### 필수 입력 항목

- **신차가격** (만원 단위)
  - 예: 3000 (3천만원)
  - 선택 옵션 포함 가격을 입력하세요

- **연월식** (YYYY-MM 형식)
  - 예: 2020-01, 2023-09
  - 다른 형식도 지원: 202001, 2020/01 등

- **주행거리** (km 단위)
  - 예: 50000 (5만km)

- **배기량** (cc 단위)
  - 예: 2000 (2000cc)
  - 전기차/수소차는 0 입력

- **색상**
  - 드롭다운 목록에서 선택

- **용도변경이력**
  - N (없음) 또는 Y (있음) 선택

#### 자동 계산 항목

다음 항목들은 입력값을 바탕으로 자동으로 계산되어 표시됩니다:

- **배기량 구간**
  - 예: "1500~1999cc", "2000~2499cc" 등
  - 전기차/수소차: "0cc(전기/수소)"

- **신차가격 구간**
  - 예: "3천만원 이상 ~ 4천만원 미만", "5천만원 이상 ~ 7천만원 미만" 등

- **차나이**
  - 연월식을 기준으로 현재 시점까지의 경과 기간 계산
  - 예: "3년 5개월 (총 41개월)"

- **시간 피처**
  - 현재 월과 주차를 sin/cos 값으로 변환
  - 계절성 패턴을 모델이 학습할 수 있도록 변환

- **차종 및 연료**
  - 등급코드에서 자동으로 매핑

- **예상 클러스터**
  - 등급코드 + 배기량구간 + 신차가격구간으로 결정
  - 어떤 모델이 사용될지 미리 확인 가능

### 3. 예측 실행

**"🔮 예측하기"** 버튼을 클릭하면:

1. 입력된 정보가 전처리됩니다
2. 적절한 클러스터의 모델이 선택됩니다
3. 감가율이 예측됩니다
4. 예측 판매가격이 계산됩니다

### 4. 결과 확인

예측이 완료되면 다음 정보가 표시됩니다:

- **예측 판매가**: 예상 판매가격 (원 단위 및 만원 단위)
- **신차가격**: 입력한 신차가격
- **예측 감가율**: 신차가격 대비 하락률 (%)

**예시:**
```
예측 판매가: 18,500,000원 (1,850만원)
신차가격: 30,000,000원 (3,000만원)
예측 감가율: 38.3%
```

### 5. 상세 정보 확인

**"📋 입력 정보 확인"** 섹션을 펼치면:
- 입력한 모든 정보를 JSON 형식으로 확인 가능
- 디버깅이나 검증에 유용

### 입력 데이터 형식

시스템이 예상하는 입력 데이터의 주요 컬럼:

| 컬럼명 | 설명 | 예시 |
|--------|------|------|
| 제조사코드 | 제조사 코드 | 1 (현대), 2 (기아) |
| 모델코드 | 모델 코드 | 12345 |
| 등급코드 | 등급 코드 | 67890 |
| 세부등급코드 | 세부등급 코드 (선택) | 11111 |
| 대표차종명 | 차종명 | "쏘나타" |
| 신차가격(선택옵션포함) | 신차가격 (원 단위) | 30000000 |
| 배기량 | 배기량 (cc) | 2000 |
| 주행거리 | 주행거리 (km) | 50000 |
| 연월식 | 연식 (YYYY-MM) | "2020-01" |
| 색상 | 색상 | "흰색" |
| 용도변경이력 | 용도변경 여부 | "N" 또는 "Y" |

### 클러스터링 구조

시스템은 차량을 **6개의 클러스터(그룹)**로 분류합니다:

- **클러스터 0**: 특정 등급코드 + 배기량구간 + 가격구간 조합
- **클러스터 1**: 다른 조합
- **클러스터 2**: ...
- **클러스터 5**: ...

각 클러스터마다 별도의 LGBM 모델이 학습되어 있어, 해당 클러스터의 특성에 맞는 예측을 수행합니다.

**클러스터 결정 방법:**
```
클러스터 = f(등급코드, 배기량_구간, 신차가격_구간)
```

매핑이 없으면 해당 등급코드의 가장 일반적인 클러스터를 사용합니다.

## 주의사항 및 고려사항

### ⚠️ 중요한 주의사항

#### 1. 데이터 파일 경로

- **절대 경로 사용**: 코드에서 절대 경로를 사용하므로, 프로젝트 폴더의 위치를 변경하면 경로를 수정해야 할 수 있습니다.
- **한글 경로**: 경로에 한글이 포함되어 있어도 대부분 정상 작동하지만, 문제가 발생하면 영문 경로로 이동하는 것을 권장합니다.

#### 2. 모델 파일 무결성

- **모델 파일 손상 방지**: `lgbm_model_cluster_*.txt` 파일들은 절대 수정하거나 삭제하지 마세요.
- **버전 호환성**: LightGBM 버전이 변경되면 모델 파일을 다시 학습해야 할 수 있습니다.

#### 3. 데이터 일관성

- **학습 데이터와 예측 데이터의 일관성**: 예측 시 사용하는 데이터 형식이 학습 시 사용한 데이터 형식과 일치해야 합니다.
- **새로운 차량 추가**: 새로운 차량 모델이 추가되면 매핑 파일(`create_hierarchy_dicts.py`)을 다시 생성해야 합니다.

#### 4. 메모리 사용량

- **대용량 데이터 처리**: 데이터 파일이 매우 클 경우 메모리 부족이 발생할 수 있습니다.
- **권장 사양 준수**: 최소 4GB 이상의 RAM을 확보하세요.

#### 5. 예측 정확도

- **예측값은 참고용**: 예측값은 통계적 모델 기반이므로 실제 거래가격과 차이가 있을 수 있습니다.
- **이상치 처리**: 극단적인 값(예: 주행거리 0km, 차나이 30년 이상)은 예측 정확도가 낮을 수 있습니다.
- **데이터 범위 내 입력**: 학습 데이터의 범위를 벗어나는 입력값은 예측이 부정확할 수 있습니다.

#### 6. 클러스터 매핑

- **매핑 없음 처리**: 등급코드 + 배기량구간 + 가격구간 조합에 대한 매핑이 없으면, 해당 등급코드의 가장 일반적인 클러스터를 사용합니다.
- **정확도 영향**: 매핑이 없는 경우 예측 정확도가 낮을 수 있습니다.

## 문제 해결 가이드

### 자주 발생하는 문제와 해결 방법

#### 1. 모듈을 찾을 수 없음 (ModuleNotFoundError)

```
ModuleNotFoundError: No module named 'streamlit'
```

```bash
# 가상환경이 활성화되어 있는지 확인

pip install -r requirements.txt
```

#### 2. 파일을 찾을 수 없음 (FileNotFoundError)

**증상:**
```
FileNotFoundError: [Errno 2] No such file or directory: '.../df_car_combined.csv'
```

**해결 방법:**
1. 데이터 파일이 올바른 위치에 있는지 확인
2. 파일 경로에 한글이 있으면 영문 경로로 이동
3. `create_hierarchy_dicts.py`를 실행하여 매핑 파일 생성

#### 3. 모델 로드 실패

**증상:**
```
Cluster 0 모델 로드 실패: ...
```

**해결 방법:**
1. 모델 파일이 존재하는지 확인:
   ```bash
   ls 00_data/03_result/lgbm_models/saved_models/
   ```
2. LightGBM 버전 확인:
   ```bash
   pip show lightgbm
   ```
3. 모델 파일이 손상되었는지 확인 (파일 크기가 0이 아닌지)

#### 4. 예측 결과가 비정상적

**증상:**
- 예측가격이 0원 또는 음수
- 감가율이 100%를 초과하거나 음수

**해결 방법:**
1. 입력값 확인:
   - 신차가격이 올바른지 확인 (만원 단위인지 원 단위인지)
   - 연월식 형식이 올바른지 확인 (YYYY-MM)
   - 주행거리, 배기량이 합리적인 범위인지 확인

2. 클러스터 확인:
   - "예상 클러스터" 값이 표시되는지 확인
   - 클러스터 매핑이 올바른지 확인

3. 디버깅 정보 확인:
   - "🔍 예측 전 데이터 확인" 섹션을 펼쳐서 실제 입력 데이터 확인
   - "🔍 예측 디버깅 정보" 섹션에서 상세 정보 확인

#### 5. Streamlit 서버가 시작되지 않음

**증상:**
```
Could not start server
```

**해결 방법:**
1. 포트가 이미 사용 중인지 확인:
   ```bash
   # macOS/Linux
   lsof -i :8501
   
   # Windows
   netstat -ano | findstr :8501
   ```
2. 다른 포트 사용:
   ```bash
   streamlit run 03_app/app.py --server.port 8502
   ```

#### 6. 메모리 부족 (MemoryError)

**증상:**
```
MemoryError: Unable to allocate array
```

**해결 방법:**
1. 다른 프로그램 종료하여 메모리 확보
2. 데이터 파일 크기 확인 (너무 크면 샘플링 필요)
3. 가상환경의 메모리 제한 확인

#### 7. 한글 인코딩 오류

**증상:**
```
UnicodeDecodeError: 'utf-8' codec can't decode...
```

**해결 방법:**
1. 파일 인코딩 확인:
   - CSV 파일이 UTF-8 또는 UTF-8-sig로 저장되어 있는지 확인
2. 코드에서 인코딩 명시:

**증상:**
- 예상 클러스터가 표시되지 않음


## 기술적 세부사항

### 사용된 기술 스택

#### 머신러닝
- **LightGBM**: 그래디언트 부스팅 기반 머신러닝 모델
  - 빠른 학습 속도
  - 범주형 변수 자동 처리
  - 메모리 효율적

- **K-Modes**: 범주형 데이터 클러스터링
  - 차량을 유사한 특성으로 그룹화
  - 클러스터별 모델 학습으로 정확도 향상

#### 웹 프레임워크
- **Streamlit**: Python 기반 웹 애플리케이션 프레임워크
  - 빠른 프로토타이핑
  - 자동 UI 생성
  - 쉬운 배포

#### 데이터 처리
- **Pandas**: 데이터프레임 처리
- **NumPy**: 수치 계산

### 모델 아키텍처

#### 1. 클러스터링 단계

```
원본 데이터
    ↓
[K-Modes 클러스터링]
  - 범주형 변수 기반
  - 6개 클러스터 생성
    ↓
클러스터별 데이터 분리
```

#### 2. 모델 학습 단계

```
클러스터별 데이터
    ↓
[전처리]
  - 구간 변환
  - 범주형 변수 인코딩
  - 피처 선택
    ↓
[LightGBM 학습]
  - 하이퍼파라미터 튜닝 (Optuna)
  - 교차 검증
    ↓
클러스터별 모델 저장
```

#### 3. 예측 단계

```
사용자 입력
    ↓
[전처리]
  - 입력값 정규화
  - 구간 변환
  - 시간 피처 계산
    ↓
[클러스터 결정]
  - 등급코드 + 배기량구간 + 가격구간
    ↓
[모델 선택 및 예측]
  - 해당 클러스터 모델 로드
  - 감가율 예측
    ↓
[가격 계산]
  - 판매가 = 신차가격 × (1 - 감가율)
    ↓
결과 반환
```

### 주요 전처리 함수

#### `preprocess_utils.py`의 주요 함수

1. **`parse_연월식()`**: 연월식 문자열을 datetime 객체로 변환
2. **`calculate_car_age()`**: 차량 연령 계산
3. **`calculate_temporal_features()`**: 시간 피처 계산 (sin/cos 변환)
4. **`create_price_interval()`**: 신차가격을 구간으로 변환
5. **`create_displacement_interval()`**: 배기량을 구간으로 변환
6. **`get_cluster_from_grade_displacement_price()`**: 클러스터 결정
7. **`map_grade_code_info()`**: 등급코드에서 차종, 연료 등 정보 추출

#### `00_prepare_for_LGBM.py`의 주요 함수

1. **`drop_columns_for_lgbm()`**: 불필요한 컬럼 제거
2. **`categorize_displacement()`**: 배기량 카테고리화
3. **`convert_binned_features_to_ordinal()`**: 구간을 순서형 변수로 변환
4. **`convert_to_categorical()`**: 범주형 변수 변환
5. **`remove_nan_rows_in_binned_features()`**: NaN 행 제거

### 성능 지표

모델의 성능은 다음과 같은 지표로 평가됩니다:

- **MAE (Mean Absolute Error)**: 평균 절대 오차
- **RMSE (Root Mean Squared Error)**: 평균 제곱근 오차
- **R² Score**: 결정 계수

각 클러스터별 성능은 `test_results_by_cluster.json` 파일에 저장됩니다.

### 확장 가능성

시스템은 다음과 같이 확장할 수 있습니다:

1. **새로운 피처 추가**: 옵션, 사고이력 등
2. **다른 모델 추가**: CatBoost, XGBoost 등
3. **앙상블 모델**: 여러 모델의 예측을 결합
4. **실시간 학습**: 새로운 데이터로 점진적 학습
5. **API 서버**: REST API로 변환하여 다른 시스템과 연동
